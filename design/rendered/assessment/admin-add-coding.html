You are given an array of N integers sorted in non-decreasing order, which may contain duplicates. You are also given Q queries. Each query is a target value X.

For every query, find the index (0-based) of the first occurrence of X in the array. If X is not present, print −1. Your solution must run in O(log N) per query.

def first_occurrence(arr, n, target):
lo, hi, ans = 0, n - 1, -1
while lo <= hi:
mid = lo + (hi - lo) // 2
if arr[mid] == target:
ans = mid
hi = mid - 1 # keep searching left
elif arr[mid] < target:
lo = mid + 1
else:
hi = mid - 1
return ans
