First Occurrence in a Sorted Array

CodingMedium20 marks
Description

You are given an array of N integers sorted in non-decreasing order, which may contain duplicates, and Q queries. For each query X, print the 0-based index of the first occurrence of X. If X is not present, print −1. Your solution must run in O(log N) per query.

Input format

Line 1: N · Line 2: N integers · Line 3: Q · Line 4: Q targets

Constraints

1 ≤ N, Q ≤ 10⁵ · −10⁹ ≤ arr[i], X ≤ 10⁹

Sample input
7 1 2 2 2 3 5 8 4 2 5 4 8
Sample output
1 5 -1 6

def first_occurrence(arr, n, target):

while lo <= hi:
mid = lo + (hi - lo) // 2

ans, hi = mid, mid - 1
elif arr[mid] < target:
lo = mid + 1

return ans
